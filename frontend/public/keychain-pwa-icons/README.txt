Sugestão:
1. Copie os PNGs para: src/assets/icons/
2. Copie favicon.ico para: src/
3. Use manifest-icons.json como referência para atualizar seu manifest.webmanifest.

O arquivo keychain-icon-master.png é a versão mestre com fundo transparente.
O arquivo keychain-icon.webp pode ser usado dentro da interface da aplicação.
